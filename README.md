# Hurrygoodjob-Text

图片文字工作室 · v10。米灰仪器风格的浏览器编辑器，支持手机尺寸布局、静态文字和动态文字。

**[直接打开使用](https://hurrygoooodjob.github.io/hurrygoodjob-text/)**

无需安装或登录。图片处理、主体识别与草稿保存在当前浏览器中；模型从本站加载，不上传照片到图片处理服务。首次点选主体需要下载约30MB模型和配套运行资源。内置人像为虚构演示素材。

## 使用方法

1. 首屏上传1–9张照片或点击“试用示例”，选择画幅与图片适配，再“开始编辑”。支持1:1、3:4、4:3、9:16、16:9、3:2、2:3。
2. 选择效果并输入文字。在“排布”“字效”“动态”切换参数；画布下方可直接开关ASCII。
3. 主体环绕、沿主体轮廓等效果可点击“点选主体”，再点击照片中人物或物体内部。主体环绕与立体螺旋各自保存最多6组文字，先选组再调整其旋转、位置、大小与字效。
4. 自定义路径：选择该效果→“绘制路径”→在照片上按住鼠标或单指画线→松手预览→“完成路径”。开启动态后文字沿线运动。取消会保留原路径，只有完成才保存为一次可撤销操作。
5. “保存”生成PNG或动态视频，预览后下载或分享。需要继续编辑时，在顶部“文件”中“保存工程”，以后用“打开工程”恢复。

画布可放大缩小、放大后拖动查看。短屏或软键盘占用空间时，参数区允许内部滚动。

## 功能

- 13种文字效果：主体环绕、沿主体轮廓、平面螺旋、立体螺旋、自定义路径、文字连线、波浪文字、字符雨、圆形环绕、漂浮网格、字符旋涡、旗帜波动、冲撞时钟。
- 全部图片组成统一画布，文字跨多图呈现，ASCII作用于整个拼图。
- 描边、外发光、投影、透明度；环绕和立体螺旋各组独立设置。
- 自定义路径支持平滑、闭合、重复、正反方向、起始位置、字距与速度。当前为单条二维路径。
- 撤销重做、浏览器自动草稿、工程文件、PNG及浏览器支持的视频格式。

v10移除了“透视隧道”“醒目标语”。旧工程分别迁移为“波浪文字”“冲撞时钟”，保留照片和文字，效果外观会改变。

## 草稿与工程

工程写入版本10，支持读取版本2–10。v10草稿独立保存；主动选择“恢复上次作品（含旧版）”时，只读查找同一浏览器同源旧稿，之后仅保存到v10。

本机localhost、不同浏览器或不同域名的草稿不会自动出现在本站。迁移作品请先在原入口保存工程，再在这里打开。浏览器草稿不能代替手动工程备份。旧版编辑器不能读取版本10工程。

## 本地开发

需要Node.js 18+，没有需要安装的运行依赖。

```sh
npm start
```

打开终端显示的本地地址，默认 `http://127.0.0.1:4203/`。

```sh
npm test
npm run build
```

测试覆盖数据、迁移、历史、IO、路径、交互、几何和字效。构建输出 `dist/Hurrygoodjob-Text-v10.html` 与 `dist/assets/`。普通编辑代码与示例内嵌在HTML中；新主体识别仍需要配套assets通过HTTP/HTTPS加载。

浏览器Canvas回归页放在 `tests/*.html`，需从本仓库根目录启动通用静态HTTP服务访问；应用开发服务器仅开放编辑器、src及assets。浏览器回归覆盖实际像素、遮挡、多图、路径和导出，不能用Node模拟画布替代。

## 部署

仓库根目录可直接作为GitHub Pages发布源：`main`分支、`/(root)`。`.nojekyll`保持静态文件原样发布。其他静态托管也可使用 `index.html`、`src/` 和完整 `assets/`。

资源地址相对当前站点目录解析，支持仓库子路径。保留两套WASM：分别供Worker与兼容回退使用。服务器须正确返回JavaScript与WASM的MIME类型。

## 能力边界

新照片最长边最多1600px，预览最长边最多900px，PNG上限12MP。一个拼图只选择一个活动主体。主体识别、轮廓和遮挡是二维蒙版与三维文字投影，不恢复真实三维身体表面。

立体螺旋已减少重复投影、网格细分和排序开销；高圈数、多组、小字及大范围字效仍可能卡顿。视频实时录制的格式、流畅度和系统分享能力取决于浏览器与设备，录制时保持页面可见。真实iPhone、Android、Safari及系统相册流程尚未全面实测。

## 源码导航

- `src/model.js`：数据、迁移、历史与分组身份。
- `src/renderer.js`、`ring.js`、`projection.js`、`contour.js`、`path.js`：图像、ASCII与文字渲染。
- `src/app.js`、`styles.css`：界面与手势；`io.js`：工程、草稿和导出。
- `src/subject.js`：本地主体识别；`boot.js`：开机动效。
- `assets/vendor/THIRD-PARTY-NOTICES.md`：第三方来源、许可和修改声明。
